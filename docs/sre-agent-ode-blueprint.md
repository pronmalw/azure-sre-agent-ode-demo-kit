# SRE Agent ODE reduction blueprint

This demo kit shows a repeatable pattern for reducing ODE:
1. Capture customer impact and service symptoms.
2. Correlate signals across app, host, Cosmos DB, and Azure SQL.
3. Route to the most likely owner with confidence.
4. Separate safe actions from approval-required changes.
5. Verify recovery against objective criteria.

The story is reusable for EMEA field engagements where the value proposition is fewer unnecessary escalations and faster root-cause isolation.
