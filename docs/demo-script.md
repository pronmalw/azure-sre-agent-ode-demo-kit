# 15-minute demo script

1. **Opening pain (2 min)** — explain the challenge of triaging noisy incidents and unnecessary escalations.
2. **Architecture walkthrough (2 min)** — show the split between Cosmos DB and Azure SQL.
3. **Healthy experience (2 min)** — browse products and show the `/ops` baseline.
4. **Trigger the incident (2 min)** — enable the mixed-incident toggles and start synthetic load.
5. **Observe impact (2 min)** — highlight p99 latency, 429s, CPU, and checkout impact.
6. **Run Azure SRE Agent (3 min)** — open `/sre-agent`, generate the report, and walk through ownership, evidence, safe actions, and do-not-do guidance.
7. **Recover (2 min)** — reset chaos, stop load, run recovery verification, and close with the ODE reduction message.
